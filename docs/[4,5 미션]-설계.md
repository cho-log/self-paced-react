[4단계]
what : Header 의 레스토랑 추가 버튼을 클릭하면 추가 폼이 모달로 떠야함

how :

- AddRestaurantModal 을 사용하면 됨
- Header 에 onAddClick prop 추가해서 모달 열기 상태 제어
- App 의 restaurants 를 useState 로 관리 (추가 핸들러 prop 으로 전달)
- category를 선택 -> <input/>, <textarea/>에 값을 입력 -> 추가하기 버튼 클릭 -> 목록에 추가 후 모달 닫기
- 폼 값은 uncontrolled (FormData) 방식으로 수집
- 유효성 검사 X
- id 는 Date.now() 값을 임의로 할당
- option을 재사용할 수 있는 Modal 컴포넌트(title, onClose, children)를 만들어 AddRestaurantModal, RestaurantDetailModal을 Modal 사용해서 리펙토링

[5단계]
what : 레스토랑 목록을 API 로 불러오고, 추가 시 POST 후 목록을 다시 불러와야 함

how :

- 첫 마운트 시 GET http://localhost:3000/restaurants 호출 → restaurants state 에 저장
- API 호출은 useEffect 안에서 실행 (side effect)
- restaurants 초기값은 빈 배열 ([]) 로 변경
- 추가하기 버튼 클릭 시 POST 요청 → 성공하면 모달 닫고 GET 다시 호출 (refetch)
- fetch 로직은 fetchRestaurants 함수로 분리해 useEffect / 추가 후 둘 다 재사용
- API base URL 은 상수로 분리
- 로딩/에러 상태는 고려하지 않음
